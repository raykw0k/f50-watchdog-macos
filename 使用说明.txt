F50 B16 无人值守监控（macOS）

把整个 f50-tools 文件夹拷到最终无人值守的 Mac mini，再安装。
当前测试电脑上没有安装或启用自动监控。

安装：
1. 将 F50 插回 Mac mini。需正常识别为 USB 网卡，可访问 192.168.0.1。
2. 确认已有 Python 3.9+：python3 --version
   如无 Python，可通过已有 Homebrew 执行 brew install python。
3. 在终端输入 cd 后拖入 f50-tools 文件夹，按回车。
4. 执行：bash install.sh
5. 先输入 Mac 管理员密码，再输入 F50 管理密码（回车默认 admin）。
   两次密码输入不显示字符。

安装器先检查 B16 固件、通过 F50 ping Google、以及管理登录。
检查不通过会停止，不启用监控；安装本身不重启 F50。
配置密码保存在 /Library/Application Support/F50Watchdog/config.json，
权限为600，仅安装账户及root可读。程序以安装账户身份运行。

运行规则：
- ping 目标为 Google DNS 8.8.8.8（IP，避免 DNS 故障干扰检测）。
- ping 绑定通往 F50 的网络接口，防止另一条 Wi-Fi 网络掩盖 F50 断网。
- 约每秒探测一次，每次有超时上限；从首次失败计时，连续满20秒后触发。
  探测和调度会带来约1至数秒误差，不是硬实时计时器。
- 每次程序启动先等180秒，给 Mac、USB 和移动网络建立连接。
- 首次连续20秒失败时尝试重启；发送前把等待状态保存到磁盘。
- 每次重启请求完成后等待整整300秒，不会在这5分钟内再次重启。
- 300秒到时，ping仍失败就再次尝试重启，然后重新等待300秒，如此循环。
- 300秒到时，ping成功就恢复正常监控；下一次连续20秒失败再重启。
- 不再要求连续通网60秒，也不限制每次断网只能重启一次。
- 请求失败、超时或认证失败同样等300秒再检查重试，不快速重复请求。
- 管理接口死机时只能每5分钟重试，软件无法强制切断USB供电。
- 脚本/机器重启后若发现之前处于等待状态，会重新等满300秒再检查。
- 只支持已实测的 F50_FLYMODEM_ZYV1.0.0B16，不修改 USB/ADB/网络协议。

检查服务状态（应看到 state = running）：
sudo launchctl print system/local.f50.watchdog

查看日志：
tail -n 50 "/Library/Application Support/F50Watchdog/state/watchdog.log"
主日志自动轮转：每份1MB，保留3份旧日志。
启动异常另看同目录 service.err。

停止并移除开机启动：
在本安装包文件夹运行：bash install.sh --uninstall
配置和日志仍保留，重新安装也保留断网等待状态。

手动重启（无须安装监控）：
python3 f50_reboot.py --reboot
按提示输入 F50 管理密码；或用 F50_PASSWORD 环境变量提供密码。

自动运行是系统 LaunchDaemon，开机且磁盘解锁后即运行，不必登录桌面。
如果开启了 FileVault，冷启动通常仍需要先解锁磁盘；本安装器不修改它。
也不修改 Mac 睡眠设置。无人值守 Mac 需保持唤醒，睡眠期间无法监控。
如果8.8.8.8本身不可达/ICMP被拦截，也会被判为断网，但仍按每5分钟重试，直到目标恢复可达。

本包已验证：重启接口实机测试、断网时序/等待状态自动测试、安装plist语法。
最终 Mac mini 的安装及开机运行仍须在那台机器上执行并确认。
